Tech Stack

Frontend   client/

Vue 3 + Vite, port 3000
  • vue ^3.4.21 — Composition API, no Pinia
  • vue-router ^4.3.0 — client-side routing
  • axios ^1.6.7 — HTTP client
  • vite ^5.2.0 with @vitejs/plugin-vue ^5.0.4
  • State: ref() / computed() + shared composable for filters

Backend   server/

Python FastAPI, port 8001
  • fastapi >=0.110.0 — routes and validation
  • uvicorn >=0.24.0 — ASGI server
  • pydantic >=2.5.0 — request/response models
  • Dev: pytest, pytest-asyncio, httpx, pytest-cov
  • Package management via uv

Data   server/data/

JSON files, loaded at startup
  • inventory.json — items, SKU, warehouse, stock
  • orders.json — 12 months of orders
  • demand_forecasts.json — forecast + trend
  • backlog_items.json, purchase_orders.json
  • spending.json, transactions.json

Data Flow — Dashboard Loads Summary

  1. User navigates to /.
  2. Dashboard.vue mounts; onMounted() calls loadDashboardData().
  3. Current filters (period, warehouse, category, status) are read from the shared filter composable.
  4. api.getDashboardSummary(filters) in client/src/api.js builds the query string.
  5. axios.get('http://localhost:8001/api/dashboard/summary?...') sends the request.
  6. FastAPI routes to get_dashboard_summary() in server/main.py.
  7. Handler applies apply_filters() and filter_by_month() against in-memory inventory_items, orders, and backlog_items from mock_data.py.
  8. JSON files in server/data/ were loaded once at module import.
  9. Handler computes total_inventory_value, low_stock_items, pending_orders, total_backlog_items, total_orders_value and returns JSON.
  10. Dashboard.vue stores the response in a ref; computed properties drive the rendered KPIs and SVG charts.
